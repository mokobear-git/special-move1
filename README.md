# WORLD CLASH ― 2D対戦格闘ゲーム

ブラウザで動く1対1の2D対戦格闘ゲーム（HTML5 Canvas、外部ライブラリなし）。
`index.html` をブラウザで開くだけで遊べる。

## モード
- **アーケードモード**：キャラクターごとのストーリー（プロローグ／エンディング）付きで、CPU 5人と連続対戦。最終戦は宿敵。ステージが進むごとにCPUレベルが上昇。敗北時はコンティニュー可能。
- **バーサス（1P vs CPU）**：対戦相手・ステージ・難易度（Lv1〜8）を選んで1試合ずつ対戦。

## ルール
- 画面上部に両者の体力ゲージ。ラウンド制限時間は99カウント。
- 一方の体力が尽きるか時間切れでラウンド終了。体力の残り割合が多い側がラウンド勝者。
- 2ラウンド先取で勝利（最大3ラウンド）。引き分けラウンドは双方に1勝が入り、引き分け試合はプレイヤーの負け扱い。

## 操作
| 操作 | キー |
|---|---|
| 移動 / ジャンプ / しゃがみ | ← → / ↑ / ↓ |
| パンチ 弱・中・強 | Z ・ X ・ C |
| キック 弱・中・強 | A ・ S ・ D |
| 必殺技ボタン（SP） | Space |
| 超必殺技（スーパーアーツ） | V（SAゲージ満タン時） |
| ガード | 相手と逆方向（しゃがみガードは斜め下後ろ） |
| 投げ | 密着して → または ← ＋ 強P |
| ポーズ | Esc / P |
| 判定表示（デバッグ） | H |

ゲームパッド（標準配置）にも対応。

メニュー画面は項目を直接タップ（PCではクリック）して選べる。キャラクター・ステージ・レベルは1回目のタップで選択、もう一度タップするか「決定」ボタンで確定。

スマホ・タブレットでは画面にタッチ操作用の十字パッドとボタン（弱P/中P/強P、弱K/中K/強K、SP、SA、決定、戻る/ポーズ）が表示される。横持ちではゲーム画面に重ねて、縦持ちではゲーム画面の下に表示される。

### 必殺技
方向キー1つ＋必殺技ボタンだけで出せる（コマンド入力不要）。
- `→（またはニュートラル）＋SP`
- `↓＋SP`
- `←＋SP`
- 超必殺技：`V`（ゲージを100消費）

### 攻撃の性質
- 弱攻撃は発生が速く隙が小さい。強攻撃は高威力だが動作が重く隙が大きい。中攻撃はその中間。
- 弱→中→強の通常技は、ヒット／ガード時に上位の通常技や必殺技へキャンセル可能（コンボ）。
- ジャンプ攻撃は立ちガードのみ、しゃがみ弱K・中K・強K（足払い）はしゃがみガードのみで防御可能。
- 必殺技・超必殺技はガードしても削りダメージを受ける。

## 効果音
WebAudio でその場合成（音声ファイル不要）。最初に画面やキーを操作した後から鳴る。
- パンチ：空振り「シュッ」（高く短い風切り音）、ヒット「パシッ」（乾いた破裂音）
- キック：空振り「ブンッ」（低く長い風切り音）、ヒット「ドスッ」（重く鈍い打撃音）
- 弱・中・強で音の長さと大きさが変わる
- 必殺技：発動音は技の種類ごとに異なる（飛び道具／対空／突進／跳躍／カウンター／投げ）。ヒット音も通常技とは別の爆発的な音
- 超必殺技：暗転時の上昇和音と、専用の重いヒット音
- 投げの叩きつけ、カウンター成功、ガードにも専用音

## BGM
WebAudio でその場演奏（音楽ファイル不要）。M キー（スマホは BGM ボタン）でオン／オフ。設定はブラウザに保存される。
- メニュー：Aマイナーのロック調
- 京都：都節音階の琴と和太鼓
- 嵐山の竹林：尺八風の笛と琴、静かな曲調
- ニューヨーク：スラップベースのファンク
- 上海：五音音階の二胡風と銅鑼
- ロンドン：疾走感のあるブリットロック
- ストーリー画面：笛とアルペジオの穏やかな曲
- 試合終了：勝利ファンファーレ／敗北ジングル
- ポーズ中は音量を下げる
